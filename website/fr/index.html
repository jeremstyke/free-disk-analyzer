Questions fréquentes

Est-ce vraiment gratuit ?

Oui, pour de bon. Pas d'abonnement, pas de version premium, jamais.

Mes données sont-elles en sécurité ?

Chaque scan se déroule sur votre ordinateur. Free Disk Analyzer n'envoie jamais de noms de fichiers, chemins ou contenus nulle part.

Pourquoi Windows affiche-t-il un avertissement à l'installation ?

Free Disk Analyzer n'a pas encore de certificat commercial de signature de code, donc Windows SmartScreen peut le signaler comme provenant d'un éditeur inconnu. Vous pouvez vérifier votre téléchargement grâce à l'empreinte SHA-256 publiée avec chaque version.

Puis-je voir le code source ?

Oui, le code source est consultable publiquement sur GitHub. L'application compilée, elle, est gratuite à l'usage.
