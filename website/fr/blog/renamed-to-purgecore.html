Free Disk Analyzer devient PurgeCore

2026

L'application que vous connaissiez sous le nom de Free Disk Analyzer a un nouveau nom : PurgeCore. Rien d'autre ne change : même application, mêmes fonctionnalités, toujours gratuit pour toujours, même lien de téléchargement.

Pourquoi ce changement

"Free Disk Analyzer" décrivait bien la première version, un analyseur d'espace disque. Depuis, l'application est devenue un outil de nettoyage plus complet : doublons, nettoyage des navigateurs, RAM, gestion du démarrage, infos pilotes. L'ancien nom ne décrivait plus ce que l'application fait réellement, il était temps d'en choisir un qui ne soit pas lié à une seule fonctionnalité.

Ce qui a réellement changé

  • Le nom affiché de l'application, le titre de la fenêtre, et le nom du programme installé
  • Les fichiers téléchargeables : PurgeCore-Setup.exe et PurgeCore-Portable.zip (anciennement FreeDiskAnalyzer-Setup.exe / FreeDiskAnalyzer-Portable.zip)
  • Ce site et son image

Ce qui n'a pas changé

  • Chaque fonctionnalité fonctionne exactement pareil
  • Toujours 100% gratuit, aucune version premium, rien derrière un paiement
  • Toujours entièrement local, rien concernant vos fichiers ne quitte jamais votre ordinateur
  • L'URL du dépôt GitHub et le vérificateur de mise à jour fonctionnent tous les deux comme avant ; si vous avez une ancienne version installée, la mise à jour en un clic dans l'application récupérera la nouvelle version normalement

Vous avez déjà Free Disk Analyzer installé ? Mettez simplement à jour comme d'habitude, l'installateur détecte l'installation existante et la met à niveau sur place sous le nouveau nom, pas besoin de désinstaller d'abord.

Télécharger PurgeCore

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
