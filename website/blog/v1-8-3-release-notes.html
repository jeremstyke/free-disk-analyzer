PurgeCore v1.8.3: A Full Code Audit

2026

No new features in this one, a full pass through the codebase looking specifically for bugs. Three real ones found.

Fixed: Startup Manager could show PurgeCore itself as a "startup item"

Enabling "Start with Windows" in Settings and PurgeCore's own Startup Manager list both touch the same registry key, but weren't aware of each other. That meant PurgeCore's own entry could show up in the general Startup Manager list, and if it got disabled from there instead of from Settings, the Settings checkbox and the actual registry state would quietly disagree with each other. PurgeCore's own entry is now excluded from that list entirely, it's managed from Settings only, as it always should have been.

Fixed: a naming leftover from the PurgeCore rename

The registry value used for "Start with Windows" still said "FreeDiskAnalyzer" under the hood, missed when the app was renamed. It's "PurgeCore" now, and anyone who had it enabled before this fix gets the old entry cleaned up automatically, no orphaned leftovers.

None of this changes what the app does, just makes sure it actually does what it says, every time.
