Free Disk Analyzer v1.0.2: In-App Update Notifications

2026

v1.0.2 is a small, focused release: it adds update notifications inside the app itself, so future versions won't require checking GitHub manually.

New: update banner

On launch, Free Disk Analyzer quietly checks whether a newer version has been released. If one has, a banner appears at the top of the app, on every tab, with the version number and two choices: download and install right away, or dismiss it and keep using the current version.

New: one-click install

Choosing to update downloads the new installer in the background and launches it directly, no browser, no manual download step. The installer now automatically closes the running app, installs over it, and reopens it when done, so there's nothing else to click through.

Why this matters

v1.0.1 added a Cleanup section (duplicates, old files, empty folders, a RAM optimizer) and CSV export, but anyone who had already installed v1.0.0 had no way to know those features existed without checking GitHub. This closes that gap going forward.

What stayed the same

The check itself only reads the public release list on GitHub, nothing about your files, your drive, or your usage is involved or sent anywhere. If GitHub is unreachable, the app just stays quiet about it and works normally.

Already on v1.0.1? The next release after this one will show up as a banner automatically, no need to check back here manually.
