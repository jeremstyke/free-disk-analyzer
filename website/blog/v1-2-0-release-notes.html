PurgeCore v1.2.0: Startup Manager

2026

v1.2.0 adds a Startup Manager to the Performance tab.

New: Startup Manager

Alongside Free up RAM in the Performance tab, there's now a list of apps registered to launch when Windows starts. Each one has a toggle: turning it off doesn't uninstall anything, it just stops the automatic launch, and it can be turned back on any time. A separate "Remove" button unregisters an entry permanently if you're sure you don't want it back.

Only your own account's entries are shown (the registry Run key and your personal Startup folder), nothing shared system-wide. That keeps it working without needing administrator rights, consistent with how the rest of the app runs.

Already have an earlier version installed? The installer detects it, closes the running app, installs over it, and reopens it automatically, no need to uninstall first.
