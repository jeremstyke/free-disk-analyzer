PurgeCore v1.6.2: Report a Bug, More Color

2026

A small release focused on two things: making it easier to tell us when something's wrong, and making the interface feel a bit more alive.

New: Report a bug

A "Report a bug" button is now available in the sidebar and on the About page. It opens a new GitHub issue directly, no need to dig through the repository to find where to file one.

More color on the Dashboard

The storage-by-category breakdown now cycles through the app's full accent palette (blue, teal, violet, amber, rose) instead of everything being the same blue. Easier to tell categories apart at a glance.

A more satisfying click

Buttons now have a small bounce when you release a click, instead of snapping back flat. Small detail, but it's the kind of thing that adds up.

Run into something odd? The new Report a bug button is the fastest way to let us know.

Download v1.6.2

Free forever, no account, no trial.

Download for Windows

No commercial code-signing certificate yet, so Windows may show a brief "unknown publisher" warning on first run. The source is public on GitHub, and each release is published with a SHA-256 checksum you can verify.
