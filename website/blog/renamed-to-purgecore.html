Free Disk Analyzer Is Now PurgeCore

2026

The app you knew as Free Disk Analyzer has a new name: PurgeCore. Nothing else changes, same app, same features, same free-forever approach, same download link.

Why the change

"Free Disk Analyzer" described the first version well, a disk space analyzer. Since then the app grew into a fuller cleanup tool: duplicates, browser cleanup, RAM, startup management, driver info. The old name stopped describing what the app actually does, so it was time for something that isn't tied to just one feature.

What actually changed

  • The app's display name, window title, and installed program name
  • The downloadable files: PurgeCore-Setup.exe and PurgeCore-Portable.zip (previously named FreeDiskAnalyzer-Setup.exe / FreeDiskAnalyzer-Portable.zip)
  • This website and its branding

What didn't change

  • Every feature works exactly the same
  • Still 100% free, no premium tier, nothing paywalled
  • Still fully local, nothing about your files ever leaves your computer
  • The GitHub repository URL and the update checker both still work as before, if you have an older version installed, the one-click update in the app will pick up the new release normally

Already have Free Disk Analyzer installed? Just update as usual, the installer detects the existing install and upgrades it in place under the new name, no need to uninstall first.
