PurgeCore v1.8.2: Startup Manager and Cookie Whitelist Fixes

2026

Two real bugs found during a code review, both fixed here.

Fixed: toggling a startup item twice could silently fail

Disabling then re-enabling a Startup Folder shortcut (not a registry entry) in quick succession could fail without any error message, because the app kept using the shortcut's old file location after it had already physically moved. Fixed by tracking the new location correctly after each toggle.

Fixed: cookie whitelist entries pasted as full URLs

If a whitelist entry was pasted as a full URL (like "https://gmail.com") instead of a bare domain, it silently matched nothing in the browser's cookie database and protected no cookies at all. The whitelist now strips the scheme and path automatically, so pasting a full URL works the same as typing just the domain.

Also in this release

The new Uninstall feature (added in v1.8.0) got a small crash-safety fix: one oddly-formatted registry entry from a misbehaving installer could previously stop the entire program list from loading, now it's skipped individually instead.
