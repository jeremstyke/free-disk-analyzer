How to Free Up Disk Space on Windows 11: The Complete Guide

Guide

2026 · 7 min read

Windows accumulates clutter from a lot of places you never look at directly: update leftovers, hibernation state, temporary files that outlived their purpose, and installs you forgot you had. The fixes below are ordered from safest and easiest to more advanced, so start at the top and stop once you've freed up what you need.

1. Run Storage Sense

Settings > System > Storage > Storage Sense. Turn it on and run it once manually. It clears temporary files, empties the Recycle Bin after a set number of days, and can offload old files from folders like Downloads to the cloud if you use OneDrive. This is the safest starting point: Microsoft designed it specifically not to touch anything you're actively using.

2. Uninstall what you don't use

Settings > Apps > Installed apps, then sort by size. Large, rarely used applications (old games, trial software, bundled utilities from a laptop manufacturer) are usually the single biggest wins here, often bigger than anything temp-file cleanup will find.

3. Clean up the Downloads folder

It's the one folder almost everyone forgets to check, and installers, ZIP files, and video downloads pile up there for years. It's also usually safe to clear entirely, since anything actually needed has typically been moved elsewhere already.

4. Empty the Recycle Bin, properly

Deleted files sit in the Recycle Bin using their original space until it's emptied. If you haven't emptied it in a while, right-click it and check "Properties" first, it's not unusual to find several gigabytes waiting there.

5. Clear browser caches

Chrome, Edge, and Firefox each keep their own cache, and on a machine that's browsed heavily for months, this can add up to multiple gigabytes across profiles. Each browser has a "Clear browsing data" option in its settings, usually under Privacy.

6. Reduce System Restore point usage

System Restore points can quietly consume many gigabytes over time. Settings > System > About > Advanced system settings > System Protection lets you reduce the max disk usage allocated to them, or delete older restore points, without disabling the feature entirely.

7. Disable hibernation, if you don't use it

The hibernation file (hiberfil.sys) reserves space equal to a portion of your RAM, permanently, whether you use hibernation or not. If you never use it (most desktop users don't), running powercfg /hibernate off from an administrator command prompt reclaims that space immediately. Skip this one if you rely on hibernation for sleep/resume behavior.

8. Clean up the WinSxS folder, carefully

The WinSxS folder stores Windows component versions used for updates and rollbacks, and it grows over years of Windows updates. Running Dism.exe /online /Cleanup-Image /StartComponentCleanup from an administrator command prompt removes superseded versions safely. Don't delete this folder manually, it can break Windows Update.

Before you start deleting things, it helps to actually see where the space is going first, rather than guessing. Free Disk Analyzer scans a drive and shows the largest files and folders, all locally, nothing leaves your computer.

The order that makes sense

Storage Sense and uninstalling unused apps get most people most of the way there with essentially no risk. The Downloads folder and Recycle Bin usually add a meaningful chunk on top. WinSxS cleanup and hibernation are worth doing on an older machine that's never had them touched, but they're optional, not first steps.
