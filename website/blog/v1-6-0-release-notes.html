PurgeCore v1.6.0: Smoother Interface

2026

v1.6.0 doesn't add a new feature, it makes the existing interface feel more responsive. Same functionality throughout, just less abrupt to use.

Smoother buttons

Buttons across the app now transition smoothly on hover instead of snapping to a different state instantly, and give a small tactile "press" effect when clicked.

Animated sidebar

The highlight that shows which tab is selected, and the hover state as you move through the sidebar, now fade in and out instead of switching abruptly.

Fade-in page transitions

Switching between tabs now fades the new page in gently rather than swapping content instantly.

Small changes, but the kind that add up. If you'd noticed the interface felt a bit stiff before, this is aimed at that.
