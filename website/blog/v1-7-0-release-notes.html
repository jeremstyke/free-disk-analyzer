PurgeCore v1.7.0: A Real Cleanup Bug Fixed, and a New Look

2026

This is a bigger release than usual: one real bug worth knowing about, and a genuine redesign, not just a tweak.

Fixed: System cleanup could report freeing space it didn't actually free

The Temp files and Recycle Bin cleaner had a real bug: it didn't check whether each individual file actually got deleted before reporting success. Temp files are commonly locked by running programs, so if deletion failed silently for some or all of them, the app could still say "Freed X GB" when little or nothing had actually happened. This is now fixed, the app measures and reports only what was genuinely deleted.

A bolder, more colorful design

The interface has a real visual refresh: a vibrant gradient sidebar (blue, violet, teal), gradient-filled buttons, colorized navigation icons, and more animation throughout, a bouncier feel on hover and selection, a pulsing beta badge, and a proper loading indicator during scans and cleanups.

Blog moved to its own tab

Release notes and guides used to share space on the Dashboard with everything else. They now have a dedicated Blog tab, freeing up room for a bigger, more visible NordVPN recommendation card on the Dashboard.

Drivers are now clickable

Clicking a driver in the Explore tab now shows how long ago it was updated in plain language ("3 years ago" instead of a raw date), a short explanation of what a driver actually does and why updating is optional, then offers to open the manufacturer's site, rather than jumping straight there.

Also in this release

  • "Report a bug" now opens an email instead of a GitHub issue
  • The update banner used to fail silently on a network timeout or a declined Windows security prompt, it now shows a clear message explaining what happened
