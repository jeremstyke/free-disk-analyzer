PurgeCore v1.8.0: Uninstall Programs

2026

A new tool in the Cleanup tab: uninstall programs without opening Windows Settings, sorted so the biggest space users are easy to spot first.

New: Uninstall

The Uninstall pill lists every installed program, largest first, with a search box to jump straight to one. Clicking Uninstall runs that program's own official uninstaller, the exact same one Windows' "Apps & features" would run, PurgeCore doesn't reimplement or guess at anything here.

What this deliberately doesn't do

Some cleaners try to also delete leftover files and registry entries after an uninstall finishes. We left that out on purpose: matching stray files and registry keys to the program that used to own them is unreliable, and getting it wrong risks removing something a different program still needs. That's the same reasoning behind not having a registry cleaner at all. Uninstall does exactly one job, cleanly.

Combine this with the Large Files & Folders view in Explore: if a program you never use turns out to be one of the biggest things on your drive, now there's a one-click way to deal with it.
