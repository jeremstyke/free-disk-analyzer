Frequently asked questions

Is it really free?

Yes, for good. There's no subscription and no premium tier, ever.

Is my data safe?

Every scan happens on your computer. PurgeCore never uploads file names, paths, or contents anywhere.

Why does Windows show a warning when I install it?

PurgeCore doesn't yet have a commercial code-signing certificate, so Windows SmartScreen may flag it as from an unknown publisher. You can verify your download with the SHA-256 checksum published alongside each release.

Can I see the source code?

Yes, the source code is publicly viewable on GitHub. The compiled app itself is free to use.

What's the difference between the installer and the portable version?

The installer (PurgeCore-Setup.exe) installs PurgeCore normally: Start Menu shortcut, entry in "Installed apps", one-click updates. The portable version (PurgeCore-Portable.zip) is a folder you unzip and run from anywhere, a USB drive, a personal folder, no installation, no admin rights needed, and nothing left behind in the registry or Program Files. Handy for working on someone else's PC or on machines where you can't install software. Same app either way, just no auto-update or shortcuts with the portable version.
