Privacy Policy

Free forever. Privacy first. This is what that actually means, in detail.

What stays local, always

Drive, folder, and file names and paths, file sizes, types and dates, and every scan result stay on this computer. The scan engine reads your file system directly, there is no server involved in analyzing a disk.

What can be sent, anonymously, only if you opt in

If you enable analytics in Settings, the following minimal, anonymous data may be sent: that an installation happened, that the app was launched, the number of scans performed (a count, not what was scanned), the application version, the Windows version, and an approximate country. This is off by default, and can be turned off at any time in Settings.

What is never collected, under any circumstance

  • Your name, email address, or Microsoft account
  • File names, file paths, or file contents
  • Folder names or folder structure
  • Detailed disk contents or file lists
  • Any identifier that could be used to fingerprint your device or link scans to you across sessions
  • Any hidden or undocumented telemetry

Offline use

PurgeCore works fully offline. Disabling your internet connection does not affect scanning, results, or any core feature.

Affiliate links

Some entries in the app (currently the NordVPN card on the Dashboard) are affiliate links, see the Partners section for the full list. Clicking one opens your browser and sends you to the partner's website; from that point, the partner's own privacy policy applies. PurgeCore itself does not track which links you click.

Changes to this policy

If this policy changes, the update will be reflected here and in the app's own Privacy tab, with version history available in the GitHub commit log.
