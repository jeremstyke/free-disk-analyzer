# Code of Conduct

## Our pledge

We want participation in PurgeCore to be a harassment-free experience for everyone, regardless of experience level, background, or identity.

## Expected behavior

- Be respectful in issues, pull requests, and discussions
- Give and accept constructive feedback gracefully
- Focus criticism on the code and ideas, not the person

## Unacceptable behavior

- Personal attacks, insults, or derogatory comments
- Harassment in any form
- Publishing others' private information without consent

## Enforcement

Violations can be reported to **juryjeremy@gmail.com**. The maintainer will review reports and may remove comments, close issues/PRs, or ban contributors who violate this code of conduct.

## Scope

This code of conduct applies within all project spaces (GitHub issues, pull requests, discussions) and when representing the project in public spaces.
